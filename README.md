# Sales Data Analysis 📈

## Project Overview
This project analyzes sales data to identify trends, product performance, and monthly revenue patterns using Python.

## Tools Used
- Python
- Pandas
- Matplotlib

## Dataset Information
The dataset contains:
- Sales date
- Product name
- Region
- Sales amount

## Analysis Performed
- Data cleaning
- Monthly sales trend analysis
- Product-wise sales summary
- Visualization using bar charts

## How to Run
1. Clone the repository  
2. Install dependencies  
   `pip install -r requirements.txt`  
3. Run the script  
   `python src/sales_analysis.py`

## Output
- Sales summary by product
- Monthly sales visualization
